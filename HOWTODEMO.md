# HowToDemo — Лента контура (PoC)

Сценарий приёмки всего PoC целиком. Фиксируется до начала работ и не меняется
после старта.

**Что демонстрируем:** человек закрывает развилку агента одним касанием в ленте,
и контур продолжает работу — без захода в GitHub, Temporal и `docker logs`.

**Что НЕ демонстрируем:** доступ с телефона, пуш-уведомления, работу без
ноутбука, вторую пару рук, перенос на стенд. Всё это — после подтверждения PoC.

---

## Условия прогона

| Что | Значение |
|---|---|
| Где крутится | ноутбук, `~/projects/poh-org/poh-feed-poc` |
| Лента | GoToSocial `0.21.2`, `127.0.0.1:8080` |
| Клиент | Phanpy, `127.0.0.1:8081` |
| Мост | `bridge`, Python 3.12 |
| Контур | читается по SSH через `poh-stand` и по GitHub API |
| Изменений в контуре | **ноль** |

**Предусловие, которое проверяется шагом, а не подразумевается:** в Temporal
существует воркфлоу, припаркованный в ожидании решения человека. Без него акт 4
проверяет пустоту и врёт об успехе.

---

## Ограничение приёмки, известное заранее

**Часть шагов принимается только человеческим глазом, и это не лень, а свойство
задачи.** Проверяемая гипотеза звучит как «механика читается и работает
руками» — её нельзя подтвердить кодом возврата. Такие шаги помечены
`ГЛАЗАМИ`; они обязательны и не могут быть зачтены автоматически.

Обратное тоже верно: всё, что можно проверить кодом, проверяется кодом.
Вердикт по машинным шагам считает скрипт, а не впечатление.

## Сценарий

### Акт 1. Лента живёт и наружу не смотрит

**1. Инстанс отвечает.**
```bash
curl -fsS http://127.0.0.1:8080/api/v1/instance | python3 -c 'import sys,json;print(json.load(sys.stdin)["uri"])'
```
Ожидаемо: печатается адрес инстанса, код 0.

**2. Ни одного публичного порта.**
```bash
docker compose ps --format '{{.Name}} {{.Ports}}'
```
Ожидаемо: у каждой строки адрес `127.0.0.1`. Появление `0.0.0.0` — провал.

**3. Федерация закрыта.**
```bash
curl -s -o /dev/null -w '%{http_code}\n' \
  "http://127.0.0.1:8080/api/v2/search?q=https://mastodon.social/@Gargron&resolve=true"
```
Ожидаемо: код **не** 200. Двухсотый ответ означает, что инстанс пошёл в
внешнюю сеть — провал сценария целиком, дальше не идти.

**4. У ленты есть предел памяти.**
```bash
docker inspect poh-feed --format '{{.HostConfig.Memory}}'
```
Ожидаемо: значение не `0`.

**5. Шесть агентов и человек на месте.**
```bash
for a in issue_agent openhands pr_agent howtodemo delivery harness aleks; do
  printf '%s ' "$a"
  curl -s -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:8080/api/v1/accounts/lookup?acct=$a"
done
```
Ожидаемо: семь строк с кодом 200.

### Акт 2. Три инструмента ветки

**6. Опрос, свёртка и вложения публикуются.**
```bash
./scripts/smoke_tools.sh
```
Ожидаемо: три `OK`, затем код ответа на попытку совместить опрос и вложение —
**не** 200. Этот отказ подтверждает, что отчёт и вопрос по нему обязаны быть
двумя постами.

**7. `ГЛАЗАМИ` Инструменты работают так, как задумано.**
Открыть `http://127.0.0.1:8081`, войти под `aleks`, найти три поста из шага 6.

Ожидаемо:
- опрос показан вариантами, голос принимается, счётчик растёт;
- свёртка видна одной строкой, разворачивается нажатием, Markdown отрисован
  заголовками разделов;
- отчёт показывает две картинки сеткой, картинка открывается во весь экран.

**Зачесть этот шаг без человека нельзя.**

### Акт 3. Развилка замыкается на Temporal

Главный акт. Всё остальное — обвязка вокруг него.

**8. Развилка контура стала постом с опросом.**
```bash
cd bridge && set -a && source ../.env && set +a && .venv/bin/feed-bridge --once
```
Ожидаемо: строка `развилок опубликовано: 1`.

**9. `ГЛАЗАМИ` Пост читается и голосуется.**
В Phanpy найти новый пост от `issue_agent`.

Ожидаемо: виден вопрос, оба варианта, строка «Молчание N мин — возьму
«вариант» и скажу об этом», координаты `репозиторий · #номер`. Проголосовать.

**10. Голос доехал до контура.**
```bash
cd bridge && set -a && source ../.env && set +a && .venv/bin/feed-bridge --once
```
Ожидаемо: строка `решений отправлено: 1`.

**11. Воркфлоу снят с парковки.**
```bash
ssh poh-stand "docker exec \$(docker ps --format '{{.Names}}' | grep temporal | head -1) \
  temporal workflow describe --workflow-id <ID> --output json" \
  | python3 -c 'import sys,json;d=json.load(sys.stdin);print([e for e in json.dumps(d).split(",") if "Signal" in e][:3])'
```
Ожидаемо: в истории присутствует `WorkflowExecutionSignaled`.

**12. След остался в истине.**
Открыть Issue на GitHub.
Ожидаемо: последний комментарий — «Решение принято через ленту контура:
**вариант**».

### Акт 4. Одна задача — одна ветка

**13. Повторный обход не плодит постов.**
```bash
cd bridge && set -a && source ../.env && set +a && .venv/bin/feed-bridge --once
```
Ожидаемо: `развилок опубликовано: 0`, `событий GitHub: 0`.

**14. `ГЛАЗАМИ` Ветка читается целиком.**
В Phanpy открыть ветку задачи.

Ожидаемо: один корневой пост, под ним ответы по времени. Не россыпь отдельных
постов об одной и той же задаче.

### Акт 5. Отчёт приёмки

**15. Улики и вопрос по ним — два поста.**
```bash
cd bridge && set -a && source ../.env && set +a && .venv/bin/python - <<'PY'
from pathlib import Path
from bridge.config import Settings
from bridge.feed import Feed
from bridge.mapping import Mapping
from bridge.pump import publish_report
s = Settings.load()
print(publish_report(
    Feed.from_settings(s), Mapping(s.db_path),
    "po-helper-org/poh-demo-checkout", 149,
    passed=4, total=5, seconds=96,
    blocked=["шаг 4 — браузер на стенде не поднять по памяти"],
    shots=[Path("/tmp/shot1.png"), Path("/tmp/shot2.png")],
))
PY
```
Ожидаемо: кортеж из двух непустых идентификаторов — отчёта и опроса.

**16. Незачтённый шаг назван словами.**
Ожидаемо: в тексте отчёта присутствует «Не проверял: шаг 4 — браузер…».
Отсутствие этой строки при `passed < total` — провал: пустая проверка
неотличима от пройденной, если о ней промолчать.

**17. `ГЛАЗАМИ` Отчёт читается за две секунды.**
Ожидаемо: в ветке виден пост со скриншотами, а следом отдельный пост с опросом
«Принять как есть / Перепрогнать», отвечающий на отчёт.

### Акт 6. Повтор и отказ не ломают контур

**18. Второй сигнал не уходит.**
```bash
cd bridge && .venv/bin/pytest tests/test_pump.py::test_vote_is_sent_once -v
```
Ожидаемо: PASS.

**19. Отказ SSH несёт причину.**
```bash
cd bridge && set -a && source ../.env && set +a && STAND_SSH=nosuchhost .venv/bin/feed-bridge --once
```
Ожидаемо: в выводе строка `обход не удался: ssh nosuchhost … -> код …:` **с
текстом от ssh**, и процесс завершился штатно, а не трейсбеком. Сообщение вида
«non-zero exit status 255» без причины — провал.

### Акт 7. Простой посчитан

**20. Метрика есть и она осмысленна.**
```bash
cd bridge && set -a && source ../.env && set +a && .venv/bin/python -c \
'from bridge.config import Settings; from bridge.mapping import Mapping; from bridge.metrics import report; print(report(Mapping(Settings.load().db_path)))'
```
Ожидаемо: `Простой контура — решений: N, медиана простоя: X мин, худший
случай: Y мин.` при N ≥ 1.

## Что считается провалом

- Любой машинный шаг не совпал с ожидаемым.
- Шаг с пометкой `ГЛАЗАМИ` зачтён без человека.
- Шаг 3 вернул 200: инстанс пошёл в внешнюю сеть. Это провал сценария целиком,
  остальные шаги не имеют значения.
- Сигнал ушёл в Temporal дважды на одну развилку.
- На одну развилку создано больше одного поста.
- При `passed < total` отчёт умолчал о незачтённом шаге.
- Отказ SSH сообщил код возврата без текста ошибки.

## Что смотреть человеку после прогона

| Что | Где |
|---|---|
| Как выглядит работа целиком | Phanpy, `http://127.0.0.1:8081` |
| Что мост делал и на чём падал | `bridge.log` |
| Соответствия и идемпотентность | `bridge/bridge.db`, таблицы `poll` и `seen` |
| Что доехало до контура | комментарии в Issue и история воркфлоу |
| Сколько простоял контур | вывод шага 20 |

## Чего этот сценарий не проверяет и почему

- **Доступ с телефона** — вне PoC, требует tailnet и сертификата.
- **Работу без ноутбука** — мост спит вместе с ним; в эти часы метрика простоя
  занижена, считать её только по активным окнам.
- **Нагрузку** — один человек и несколько агентов, потолок не исследуется.
- **Перенос на стенд** — на нём свободно около гигабайта, свопа нет и рядом
  чужой прод; вопрос ставится только после подтверждения механики.
