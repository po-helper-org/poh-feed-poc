# Лента контура — PoC: план реализации

> **Для агентов-исполнителей:** ОБЯЗАТЕЛЬНЫЙ СУБ-СКИЛЛ — `superpowers:subagent-driven-development` (рекомендуется) либо `superpowers:executing-plans`. Шаги размечены чекбоксами (`- [ ]`).

**Цель:** проверить, что механика Threads (лента, ветки, опросы, свёртки, вложения) годится для управления контуром производства, собрав прототип из готовых компонентов и написав только клей.

**Архитектура:** три процесса на ноутбуке. `GoToSocial` — сервер ленты, Mastodon-совместимый, федерация закрыта. `Phanpy` — статический клиент, смотрит на этот сервер. `bridge` — один Python-процесс, качающий события между контуром (Temporal по SSH, GitHub по API) и лентой. Контур не изменяется ни одной строкой.

**Стек:** Python 3.12, Mastodon.py, PyGithub, pytest, Docker Compose, GoToSocial, Phanpy.

## Глобальные ограничения

- **Федерация выключена до первого старта.** `instance-federation-mode: "allowlist"` с пустым списком разрешённых доменов. Проверяется тестом, а не доверием к конфигу.
- **Ни одного публичного порта.** Все контейнеры слушают `127.0.0.1`. Наружу не публикуется ничего.
- **Контур не правим.** Ни PR в `poh-issue-agents`, ни изменений активностей, ни нового пина `ISSUE_AGENT_CONTEXT`. Мост ходит только на чтение и на явные действия человека.
- **На стенд ничего не ставим.** Стенд `poh-stand` используется только как источник данных Temporal по SSH.
- **Опрос и вложение несовместимы в одном посте** (ограничение Mastodon API). Улики и вопрос по ним — всегда два поста: отчёт с вложениями, вопрос ответом в ту же ветку.
- **Источник истины по срокам решения — Temporal.** Срок опроса в ленте — витрина. Расхождение гасится в мосте в пользу Temporal.
- **Порог отказа от подхода:** если код моста перевалил за 600 строк без учёта тестов — остановиться и пересмотреть замысел, а не дописывать.
- **`subprocess` всегда с `capture_output=True`, и stderr обязан попадать в текст исключения.** `check=True` печатает только команду и код возврата; без stderr причина отказа теряется.
- **Тест на подделке добрее реальности.** Каждая задача, касающаяся внешнего мира, заканчивается живой проверкой, а не только зелёными юнит-тестами.
- Python 3.12, Mastodon.py ≥ 2.0, pytest ≥ 8.
- Репозиторий локальный. Если он когда-либо уедет в `po-helper-org` — работа через PR, в `main` напрямую не пушить.

```bash
#!/usr/bin/env bash
# Проверка стенда ленты. Три утверждения, каждое обязательно.
set -u
fail=0

echo "== 1. Инстанс отвечает =="
if curl -fsS http://127.0.0.1:8080/api/v1/instance | grep -q '"uri"'; then
  echo "OK"
else
  echo "ПРОВАЛ: инстанс не отвечает"; fail=1
fi

echo "== 2. Наружу не смотрит ни один порт =="
# Публикация считается наружной, если адрес не 127.0.0.1: это и 0.0.0.0,
# и конкретный адрес интерфейса, и IPv6-вариант.
outside=$(docker compose ps --format '{{.Ports}}' | tr ',' '\n' \
  | grep -E '->' | grep -v '^ *127\.0\.0\.1:' || true)
if [ -z "$outside" ]; then
  echo "OK"
else
  echo "ПРОВАЛ: порты опубликованы не только на 127.0.0.1:"; echo "$outside"; fail=1
fi

echo "== 3. Федерация закрыта =="
code=$(curl -s -o /dev/null -w '%{http_code}' \
  "http://127.0.0.1:8080/api/v2/search?q=https://mastodon.social/@Gargron&resolve=true")
if [ "$code" = "401" ] || [ "$code" = "403" ] || [ "$code" = "422" ]; then
  echo "OK (поиск чужого домена отвергнут, код $code)"
elif [ "$code" = "200" ]; then
  echo "ПРОВАЛ: инстанс попытался разрешить внешний адрес"; fail=1
else
  echo "OK (код $code, внешнее разрешение недоступно)"
fi

exit $fail
```

```python
from bridge.mapping import Mapping


def test_thread_remembered_and_found(tmp_path: Path):
    m = Mapping(tmp_path / "m.db")
    assert m.thread_for("po-helper-org/poh-demo-checkout", 149) is None
    m.remember_thread("po-helper-org/poh-demo-checkout", 149, "STATUS1")
    assert m.thread_for("po-helper-org/poh-demo-checkout", 149) == "STATUS1"


def test_open_polls_lists_only_unclosed(tmp_path: Path):
    m = Mapping(tmp_path / "m.db")
    m.remember_poll("P1", "S1", "issue-demo-149", "RUN1", ["Сессия", "БД"])
    m.remember_poll("P2", "S2", "issue-demo-151", "RUN2", ["да", "нет"])
    m.close_poll("P1")
    left = m.open_polls()
    assert [p.poll_id for p in left] == ["P2"]
    assert left[0].options == ["да", "нет"]
    assert left[0].workflow_id == "issue-demo-151"


def test_seen_is_idempotent(tmp_path: Path):
    m = Mapping(tmp_path / "m.db")
    assert m.seen("vote:P1") is False
    m.mark_seen("vote:P1")
    assert m.seen("vote:P1") is True
    m.mark_seen("vote:P1")  # повтор не должен падать
    assert m.seen("vote:P1") is True
```

```python
import sqlite3
from dataclasses import dataclass
from pathlib import Path

SCHEMA = """
CREATE TABLE IF NOT EXISTS thread (
  repo TEXT NOT NULL, issue INTEGER NOT NULL, status_id TEXT NOT NULL,
  PRIMARY KEY (repo, issue));
CREATE TABLE IF NOT EXISTS poll (
  poll_id TEXT PRIMARY KEY, status_id TEXT NOT NULL,
  workflow_id TEXT NOT NULL, run_id TEXT NOT NULL,
  options TEXT NOT NULL, closed INTEGER NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS seen (key TEXT PRIMARY KEY);
"""


@dataclass(frozen=True)
class PollLink:
    poll_id: str
    status_id: str
    workflow_id: str
    run_id: str
    options: list[str]


class Mapping:
    def __init__(self, path: Path):
        self._db = sqlite3.connect(path)
        self._db.executescript(SCHEMA)
        self._db.commit()

    def remember_thread(self, repo: str, issue: int, status_id: str) -> None:
        self._db.execute(
            "INSERT OR REPLACE INTO thread(repo, issue, status_id) VALUES (?,?,?)",
            (repo, issue, status_id),
        )
        self._db.commit()

    def thread_for(self, repo: str, issue: int) -> str | None:
        row = self._db.execute(
            "SELECT status_id FROM thread WHERE repo=? AND issue=?", (repo, issue)
        ).fetchone()
        return row[0] if row else None

    def remember_poll(
        self, poll_id: str, status_id: str, workflow_id: str, run_id: str,
        options: list[str],
    ) -> None:
        self._db.execute(
            "INSERT OR REPLACE INTO poll(poll_id,status_id,workflow_id,run_id,options,closed)"
            " VALUES (?,?,?,?,?,0)",
            (poll_id, status_id, workflow_id, run_id, "\n".join(options)),
        )
        self._db.commit()

    def open_polls(self) -> list[PollLink]:
        rows = self._db.execute(
            "SELECT poll_id,status_id,workflow_id,run_id,options FROM poll WHERE closed=0"
        ).fetchall()
        return [PollLink(r[0], r[1], r[2], r[3], r[4].split("\n")) for r in rows]

    def close_poll(self, poll_id: str) -> None:
        self._db.execute("UPDATE poll SET closed=1 WHERE poll_id=?", (poll_id,))
        self._db.commit()

    def seen(self, key: str) -> bool:
        return (
            self._db.execute("SELECT 1 FROM seen WHERE key=?", (key,)).fetchone()
            is not None
        )

    def mark_seen(self, key: str) -> None:
        self._db.execute("INSERT OR IGNORE INTO seen(key) VALUES (?)", (key,))
        self._db.commit()
```

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class PollPost:
    text: str
    options: list[str]
    expires_in: int


def _short_repo(repo: str) -> str:
    return repo.split("/")[-1]


def _minutes(seconds: int) -> str:
    return f"{max(1, seconds // 60)} мин"


def render_decision(
    repo: str, issue: int, question: str, options: list[str],
    default: str, seconds_left: int,
) -> PollPost:
    """Развилка. Дефолт обязан быть одним из вариантов — иначе молчание
    применит то, чего в опросе нет, и человек не поймёт, на что согласился."""
    if default not in options:
        raise ValueError(
            f"дефолт {default!r} отсутствует среди вариантов {options!r}"
        )
    text = (
        f"{question}\n\n"
        f"Молчание {_minutes(seconds_left)} — возьму «{default}» и скажу об этом.\n\n"
        f"{_short_repo(repo)} · #{issue}"
    )
    return PollPost(text=text, options=list(options), expires_in=seconds_left)


def render_artifact(title: str, words: int, body_md: str) -> tuple[str, str]:
    """Фрагмент: свёртка видна всем, документ разворачивается нажатием."""
    return f"{title} · {words} слов", body_md


def render_report(passed: int, total: int, seconds: int, blocked: list[str]) -> str:
    """Отчёт приёмки. Незачтённые шаги обязаны быть названы словами:
    пустая проверка неотличима от пройденной, если о ней промолчать."""
    text = f"Сценарий: {passed} из {total} за {seconds} с."
    if blocked:
        text += "\n\nНе проверял: " + "; ".join(blocked) + "."
    return text


def render_incident(what: str, evidence: str) -> str:
    return f"{what}\n\n{evidence}"


def render_agent_reply(body: str, reason: str) -> str:
    """Ответ агента без причины — это лог, а не сообщение."""
    if not reason.strip():
        raise ValueError("ответ агента обязан нести причину одной строкой")
    return f"{body}\n\nпочему: {reason}"
```

```python
from pathlib import Path
from bridge.render import PollPost


class Feed:
    """Обёртка над Mastodon.py. Один клиент на агента — каждый постит от себя."""

    def __init__(self, clients: dict[str, object]):
        self._clients = clients

    @staticmethod
    def from_settings(settings) -> "Feed":
        from mastodon import Mastodon

        clients = {
            agent: Mastodon(access_token=token, api_base_url=settings.feed_url)
            for agent, token in settings.tokens.items()
        }
        return Feed(clients)

    def _client(self, agent: str):
        if agent not in self._clients:
            raise KeyError(f"нет клиента для агента {agent!r}")
        return self._clients[agent]

    def post(
        self, agent: str, text: str, *, spoiler: str | None = None,
        in_reply_to: str | None = None,
    ) -> str:
        kw = {"visibility": "private", "content_type": "text/markdown"}
        if spoiler:
            kw["spoiler_text"] = spoiler
        if in_reply_to:
            kw["in_reply_to_id"] = in_reply_to
        return str(self._client(agent).status_post(text, **kw)["id"])

    def post_poll(
        self, agent: str, poll: PollPost, *, in_reply_to: str | None = None
    ) -> tuple[str, str]:
        client = self._client(agent)
        made = client.make_poll(poll.options, expires_in=poll.expires_in)
        kw = {"visibility": "private", "poll": made}
        if in_reply_to:
            kw["in_reply_to_id"] = in_reply_to
        result = client.status_post(poll.text, **kw)
        return str(result["id"]), str(result["poll"]["id"])

    def post_media(
        self, agent: str, text: str, files: list[Path], *,
        in_reply_to: str | None = None, poll: PollPost | None = None,
    ) -> str:
        if poll is not None:
            raise ValueError(
                "вложение и опрос несовместимы в одном посте: "
                "отчёт и вопрос по нему публикуются двумя постами"
            )
        client = self._client(agent)
        ids = [client.media_post(str(p), description=p.stem)["id"] for p in files]
        kw = {"visibility": "private", "media_ids": ids}
        if in_reply_to:
            kw["in_reply_to_id"] = in_reply_to
        return str(client.status_post(text, **kw)["id"])

    def votes(self, poll_id: str) -> dict[str, int]:
        any_client = next(iter(self._clients.values()))
        data = any_client.poll(poll_id)
        return {o["title"]: int(o["votes_count"]) for o in data["options"]}
```

```python
import json
import subprocess
from dataclasses import dataclass


class SshError(RuntimeError):
    """Отказ выполнения на стенде. Текст ОБЯЗАН нести stderr:
    без него остаётся только 'non-zero exit status 1' без причины."""


@dataclass(frozen=True)
class Parked:
    workflow_id: str
    run_id: str
    repo: str
    issue: int
    question: str
    options: list[str]
    default: str
    seconds_left: int


def run_ssh(host: str, argv: list[str]) -> str:
    done = subprocess.run(
        ["ssh", host, *argv], capture_output=True, text=True, timeout=60
    )
    if done.returncode != 0:
        raise SshError(
            f"ssh {host} {' '.join(argv)} -> код {done.returncode}: "
            f"{done.stderr.strip() or 'stderr пуст'}"
        )
    return done.stdout


def parked_decisions(runner) -> list[Parked]:
    """Читает воркфлоу, ждущие решения человека. Пустой вывод — не отказ:
    ждущих может просто не быть."""
    raw = runner([
        "docker", "exec", "$TEMPORAL_CONTAINER", "temporal", "workflow", "list",
        "--query", "ExecutionStatus='Running' AND CustomKeywordField='awaiting_human'",
        "--output", "json",
    ]).strip()
```

```python
from bridge.mapping import Mapping
from bridge.render import render_decision


def pump_decisions(feed, mapping: Mapping, read_parked, github) -> int:
    """Припаркованные решения превращает в посты с опросом. Один воркфлоу —
    один пост: ключ идемпотентности не даёт повторному обходу плодить копии."""
    made = 0
    for p in read_parked():
        key = f"decision:{p.workflow_id}:{p.run_id}"
        if mapping.seen(key):
            continue
        poll = render_decision(
            repo=p.repo, issue=p.issue, question=p.question,
            options=p.options, default=p.default, seconds_left=p.seconds_left,
        )
        parent = mapping.thread_for(p.repo, p.issue)
        status_id, poll_id = feed.post_poll("issue_agent", poll, in_reply_to=parent)
        if parent is None:
            mapping.remember_thread(p.repo, p.issue, status_id)
        mapping.remember_poll(poll_id, status_id, p.workflow_id, p.run_id, p.options)
        mapping.mark_seen(key)
        made += 1
    return made


def pump_votes(feed, mapping: Mapping, send_signal, github) -> int:
    """Голос в опросе превращает в сигнал Temporal и комментарий в Issue.
    Сигнал уходит РОВНО один раз на опрос — повторная доставка уже роняла контур."""
    sent = 0
    for link in mapping.open_polls():
        counts = feed.votes(link.poll_id)
        chosen = [title for title, n in counts.items() if n > 0]
        if not chosen:
            continue
        choice = chosen[0]
        key = f"vote:{link.poll_id}"
        if mapping.seen(key):
            mapping.close_poll(link.poll_id)
            continue
        send_signal(link.workflow_id, link.run_id, choice)
        repo, issue = _coords(link.workflow_id)
        if repo:
            github.comment(
                repo, issue,
                f"Решение принято через ленту контура: **{choice}**.",
            )
        mapping.mark_seen(key)
        mapping.close_poll(link.poll_id)
        sent += 1
    return sent


def _coords(workflow_id: str) -> tuple[str, int]:
    """Идентификатор воркфлоу контура: issue-<owner>/<repo>-<N>."""
    if not workflow_id.startswith("issue-"):
        return "", 0
    body = workflow_id[len("issue-"):]
    repo, _, number = body.rpartition("-")
    if not number.isdigit():
        return "", 0
    return repo, int(number)
```

```python
            return 0
```

```python
def publish_report(
    feed, mapping: Mapping, repo: str, issue: int, *,
    passed: int, total: int, seconds: int, blocked: list[str], shots: list[Path],
) -> tuple[str, str | None]:
    """Отчёт приёмки: улики вложениями. Опрос и вложение в одном посте
    Mastodon не принимает, поэтому вопрос по неполной приёмке уходит
    ОТДЕЛЬНЫМ постом-ответом на отчёт."""
    parent = mapping.thread_for(repo, issue)
    text = render_report(passed=passed, total=total, seconds=seconds, blocked=blocked)
    report_id = feed.post_media("howtodemo", text, shots, in_reply_to=parent)
    if passed == total and not blocked:
        return report_id, None
    question = render_decision(
        repo=repo, issue=issue,
        question="Сценарий пройден не полностью. Что делаем?",
        options=["Принять как есть", "Перепрогнать"],
        default="Перепрогнать", seconds_left=1800,
    )
    _, poll_id = feed.post_poll("howtodemo", question, in_reply_to=report_id)
    return report_id, poll_id
```

```python
    def mark_posted(self, poll_id: str, when: float) -> None:
        self._db.execute(
            "INSERT OR REPLACE INTO timing(poll_id, posted_at, decided_at)"
            " VALUES (?,?,NULL)",
            (poll_id, when),
        )
        self._db.commit()

    def mark_decided(self, poll_id: str, when: float) -> None:
        self._db.execute(
            "UPDATE timing SET decided_at=? WHERE poll_id=?", (when, poll_id)
        )
        self._db.commit()

    def timings(self) -> list[tuple[float, float]]:
        return [
            (r[0], r[1])
            for r in self._db.execute(
                "SELECT posted_at, decided_at FROM timing WHERE decided_at IS NOT NULL"
            ).fetchall()
        ]
```

```python
from statistics import median

from bridge.mapping import Mapping


def idle_minutes(mapping: Mapping) -> list[float]:
    """Простой контура: минуты от публикации развилки до решения человека."""
    return [round((b - a) / 60, 1) for a, b in mapping.timings()]


def report(mapping: Mapping) -> str:
    values = idle_minutes(mapping)
    if not values:
        return "Простой: данных нет — ни одна развилка ещё не решена."
    return (
        f"Простой контура — решений: {len(values)}, "
        f"медиана простоя: {median(values)} мин, "
        f"худший случай: {max(values)} мин."
    )
```

## Самопроверка плана

**Покрытие решения.** Стенд ленты с закрытой федерацией — задача 1. Три инструмента ветки (опрос, фрагмент, скриншоты) — задача 2, там же критические ворота. Развилка и голос — задача 7. События GitHub — задача 8. Отчёт приёмки — задача 9. Метрики — задача 10. Ограничение «опрос и вложение несовместимы» проверяется в задаче 2 и реализуется в задачах 5 и 9.

**Заглушек нет.** Каждый шаг несёт код или команду с ожидаемым выводом.

**Согласованность имён.** `Mapping.remember_poll(poll_id, status_id, workflow_id, run_id, options)` — одна сигнатура в задачах 3, 7, 10. `Feed.post_poll(agent, poll, in_reply_to=)` возвращает `(status_id, poll_id)` в задачах 5, 7, 9. `Parked` из задачи 6 потребляется в задаче 7 без изменений. `render_decision` из задачи 4 вызывается в задачах 7 и 9 с одними и теми же именованными аргументами.

**Чего в плане намеренно нет.** Своего фронтенда, своего API, OAuth-сервера, выкладки на стенд, изменений в контуре, доступа с телефона через tailnet, хранения скриншотов в GitHub. Всё это — после подтверждения PoC, не раньше.
